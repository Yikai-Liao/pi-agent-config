# Pi Agent Config

Personal Pi package for sharing reusable skills and settings across machines.

## Install

```sh
git clone git@github.com:Yikai-Liao/pi-agent-config.git ~/pi-agent-config
cd ~/pi-agent-config
./setup.sh
```

## What is tracked

- `skills/`
- `settings.json`
- Pi package metadata

## What stays local

- `~/.pi/agent/auth.json`
- `~/.pi/agent/trust.json`
- sessions, package caches, runtime model state
